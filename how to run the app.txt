since you set up Nginx as a reverse proxy earlier, it's configured to auto-start whenever the server boots. But Streamlit itself does not auto-restart — the nohup process you started dies when the instance stops, and won't come back on its own.

So here's exactly what you need each time:

1. Start the instance: EC2 Console → Instances → select it → Instance state → Start
2. Wait ~1-2 minutes for status checks to pass
3. Connect: Instance → Connect → EC2 Instance Connect → Connect
4. In that terminal, run:
	cd resume-screening-project/resume-screening
	source venv/bin/activate
	nohup streamlit run app.py --server.port 8501 --server.address 0.0.0.0 &
	or
	cd resume-screening-project/resume-screening
	source venv/bin/activate
	nohup streamlit run app_ats.py --server.port 8501 --server.address 0.0.0.0 &
5. Now visit http://resume-screening.duckdns.org — it should load
